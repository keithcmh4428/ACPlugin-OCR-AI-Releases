# AI Scan Releases

Public, signed binary update feed for the CHANTCH **AI Scan** AutoCount plug-in.

Release assets contain only the plug-in DLL, background worker, and a detached RSA-signed manifest.
The AI Scan client verifies the manifest signature and package SHA-256 before installation. Source
code, signing keys, credentials, customer documents, and licence data are never stored here.

Official product information: [chantch.com.my](https://chantch.com.my)
